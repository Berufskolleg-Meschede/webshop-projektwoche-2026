# Security Policy

## Project status

The BKM Webshop is a school and learning project. It comes without guarantees and is not intended for production use with real customer data. The simulation has no authentication: anyone who knows a session code can join and act in that session.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or pull requests. Use GitHub's private vulnerability reporting instead: open the Security tab of this repository and choose "Report a vulnerability". Describe what you found, how to reproduce it and which part of the project it affects.

Reports are handled on a best-effort basis by the maintainers.
